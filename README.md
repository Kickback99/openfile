## 简介
soft-manager 是一款基于 INI 配置文件的智能化软件管理工具，采用 GUI 图形化界面设计，帮助用户高效管理电脑上的应用程序集合。通过灵活的配置文件管理，实现软件的快速启动、分类整理和批量操作。

## 功能介绍
1. INI 配置文件管理
2. 软件列表管理（创建、编辑、删除）
3. 导入导出功能
4. 搜索功能
5. 批量操作（删除、移动），仅完整版支持
